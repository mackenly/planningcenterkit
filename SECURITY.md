# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

Security fixes are released for the latest 1.x version. Please upgrade to the newest release before reporting an issue.

## Reporting a Vulnerability

Thank you for wanting to report a vulnerability. To get in touch, please go to [Tricities Media Group's contact form](https://tricitiesmediagroup.com/contact) and select "Security" as the purpose. This will go straight to one of the maintainers. You can also use GitHub's [private vulnerability reporting](https://github.com/mackenly/planningcenterkit/security/advisories/new) if it is enabled for this repository. Please don't open a public issue for security problems.

This library has no runtime dependencies. If you find a problem in a development dependency or in the build and release pipeline, please report it the same way.

Thanks!
